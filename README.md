# Flota MSMIN · Check list diario

App web para el check list diario de camionetas y el panel de estado de flota de MSMIN.

- `index.html`: la app completa (conductores y administradores). Se publica con GitHub Pages.
- `supabase/`: base de datos, permisos y función para administrar usuarios. Ver `supabase/INSTALAR.md`.
